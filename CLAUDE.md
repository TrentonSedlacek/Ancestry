# Sedlacek ancestry research

- When a record disagrees with the charts, keep the chart's value in the tree and add a row to the "Deviations from the historian's charts" table in `PATRILINEAL_LINE.md`. Log every deviation, including spelling differences.
- Label findings from search snippets or online trees as leads (confirmed / likely / speculative) until a record is seen.
- The user pays for no services; only suggest free sources.
